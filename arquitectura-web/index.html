Flujo operativo explicado simple

Secuencia completa desde el correo entrante hasta la decision de derivacion.

1

Llega el correo a Outlook

Workato monitorea en forma continua.

2

Workato filtra y envia

Se detectan adjuntos relevantes y se envian a la nube.

3

Se identifica el tipo de archivo

Soporta XML UBL 2.1, ZIP y PDF con texto.

4

Extraccion de datos clave

Se obtiene emisor, numero, fecha, monto y tipo documental.

5

Validacion SUNAT

Se consulta estado del comprobante y del contribuyente.

6

Prevalidacion COES

Se valida el monto reportado en la factura frente a lo estipulado en COES.

7

Clasificacion automatica

Se sugiere empresa y departamento responsable.

8

Registro en base de datos

Se guarda trazabilidad completa del documento.

9

Visualizacion en panel

El usuario revisa, ajusta si aplica y marca derivacion.

Prevalidacion de COES

Se incorpora una conexion para contrastar montos de factura con lo estipulado en COES antes de la derivacion.

Conexion de contraste

El sistema consulta COES y compara los montos reportados en la factura.

Control previo

La validacion se ejecuta antes de la clasificacion final del documento.

Carga masiva desde ZIP

Cada carpeta del ZIP se interpreta como un registro independiente y puede incluir XML, PDF y ZIP anidados.

ZIP maestro

El usuario selecciona un solo archivo ZIP desde la interfaz y el sistema lo procesa completo.

Carpeta = registro

Cada carpeta interna genera un registro nuevo con su propio conjunto de archivos y metadatos.

Archivos soportados

Se aceptan XML, PDF y ZIP, manteniendo la misma lógica de ingestión que el flujo normal.

Procesamiento iterativo

El backend expande el ZIP, agrupa por carpeta y llama al endpoint de intake para cada grupo.

Visualizacion de correos

La plataforma puede mostrar el cuerpo del correo como una ventana desplegable, útil para revisar el contexto original.

Metadatos del mensaje

La plataforma muestra información clave del correo, como remitente, destinatario y fecha de recepción.

Vista previa segura

El correo se podrá visualizar desde la plataforma como vista previa.

Uso operativo

Permite validar el correo original sin salir del tablero ni perder trazabilidad del documento.
