Rol de Workato en el flujo
Workato actúa como capa de captura y enrutamiento — no procesa ni interpreta documentos
✅ Lo que hace Workato
  • 📧Monitorea el buzón de correo (Outlook / Gmail) en forma continua.
  • 📎Detecta correos con adjuntos PDF o XML.
  • 🔍Filtra por remitente, tamaño, extensión y lista de permitidos.
  • ⬇️Descarga el adjunto en binario (bytes, no base64).
  • 📤Envía multipart/form-data a POST /api/intake con archivos en campo files, metadatos del correo (messageId, sender, subject, receivedAt) y header x-workato-secret.
  • 🔄Gestiona reintentos automáticos ante errores de red.
  • 🔔Envía alertas ante fallos reiterados.
❌ Lo que Workato NO hace
  • 🚫Leer ni interpretar el contenido del PDF/XML.
  • 🚫Clasificar tipo de documento (factura, comprobante, nota).
  • 🚫Extraer campos: número, monto, fecha, emisor.
  • 🚫Guardar datos en base de datos.
  • 🚫Generar ZIPs ni reportes exportables.
  • 🚫Deduplicar documentos ya procesados.

📄 Contrato entre Workato y GCP

Workato envía:
Archivo binario + metadatos del correo (remitente, asunto, fecha de recepción, messageId)
GCP responde:
202 Accepted con { requestId, accepted, rejected, documents[] } — incluyendo campos extraídos, tipo documental y concepto inferido
Idempotencia:
El hash SHA-256 del contenido del archivo evita reprocesar duplicados aunque Workato reintente el envío múltiples veces
